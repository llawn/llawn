# Hi there, I'm llawn!

I'm a student at **École Centrale de Lyon** 🇫🇷 and a **Neovim enthusiast**. I enjoy building tools that improve the developer experience, specifically within the Lua/Nvim ecosystem.

## Neovim Plugins

I've developed several tools to streamline local workflows:

* **[telescope-gitignore.nvim](https://github.com/llawn/telescope-gitignore.nvim)** - A Telescope extension to quickly generate and inject `.gitignore` templates from inside Neovim.
* **[colors.nvim](https://github.com/llawn/colors.nvim)** - A lightweight color highlighter/manager for Neovim.
* **[save-my-breakpoints.nvim](https://github.com/llawn/save-my-breakpoints.nvim)** - Persistence for your DAP breakpoints so they survive across sessions.
