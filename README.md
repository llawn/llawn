# Hi there, I'm llawn!

I enjoy building tools that improve the developer experience, specifically within the Nvim ecosystem.

## Tech Stack

### Core OS & Kernel

- Kernel: Linux
- OS: Arch Linux
- Disk: `btrfs`
- Bootloader: `systemd`
- Disk unlocking: `systemd-cryptsetup` (LUKS)
- Graphical boot: `plymouth`

### Desktop Environment

- Window Manager: `Hyprland`
- Desktop Shell: `Noctalia-shell`
- Greeter: `cosmic-greeter`

### Package Managers

- Native: `pacman`
- AUR: `paru`
- Flatpak: `Bazaar`

### System Services & Drivers

- Audio: `PipeWire` + `Wireplumber`
- Ethernet: `iwd` + `impala` (TUI)
- Bluetooth: `bluez` + `bluez-utils` + `bluetui` (TUI)
- Print: `CUPS`

### GUI Apps

- Browser: `zen-browser`
- File Manager: `nautilus`
- Mail: `evolution`
- Note: `Joplin`
- Terminal: `kitty`
- Viewer (Image): `ImageViewer` + `imv`
- Viewer (PDF): `Zathura`

### TUI Apps

- Editor: `neovim`
- File Manager: `yazi`
- Git: `lazygit`
- Git commit: `kofi`
- Git log: `tig`
- Jj: `lazyjj`
- Journal: `lazyjournal`
- Note: `toney`
- Sql: `lazysql`
- System monitoring: `htop`

### Shell & CLI

- Shell: `fish`
- Prompt: `tide`

#### Modern CLI Utilities

- `atuin`: SQLite-powered shell history
- `fzf` & `television`: Fuzzy finders
- `zoxide`: Smarter `cd` command
- `eza`: Modern `ls` replacement
- `bat`: Syntax-highlighted `cat` clone
- `fd`: Simplified, faster `find` alternative
- `rg` (ripgrep): Blazing fast `grep` alternative
- `dysk`: Better disk information display
- `chezmoi`: Robust dotfiles manager
- `tealdeer`: High-performance `tldr` client in Rust
- `tmux`: Terminal multiplexer
- `trash-cli`: Safe command-line trashcan management
- `gh` & `glab` & `fgj` : GitHub/GitLab/Codeberg CLI hubs
