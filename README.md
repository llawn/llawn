# Hi there, I'm llawn!

I enjoy building tools that improve the developer experience, specifically within the Nvim ecosystem.

## Tech Stack

### Core OS & Kernel

* Kernel: [linux](https://github.com/torvalds/linux)
* OS: [archlinux](https://gitlab.archlinux.org/archlinux)
* Disk: [btrfs](https://github.com/kdave/btrfs-progs)
* Bootloader: [systemd](https://github.com/systemd/systemd)
* Disk unlocking: [systemd-cryptsetup](https://github.com/systemd/systemd/tree/main/src/cryptsetup) (LUKS)
* Graphical boot: [plymouth](https://gitlab.freedesktop.org/plymouth/plymouth)

### Desktop Environment

* Window Manager: [Hyprland](https://github.com/hyprwm/Hyprland)
* Desktop Shell: [noctalia-shell](https://github.com/noctalia-dev/noctalia-shell)
* Greeter: [cosmic-greeter](https://github.com/pop-os/cosmic-greeter)

### Package Managers

* Native: [pacman](https://gitlab.archlinux.org/pacman/pacman)
* AUR: [paru](https://github.com/Morganamilo/paru)
* Flatpak: [Bazaar](https://github.com/bazaar-org/bazaar)

### System Services & Drivers

* Audio: [PipeWire](https://gitlab.freedesktop.org/pipewire/pipewire) + [Wireplumber](https://gitlab.freedesktop.org/pipewire/wireplumber)
* Ethernet: [iwd](https://git.kernel.org/pub/scm/network/wireless/iwd.git) + [impala](https://github.com/pythops/impala) (TUI)
* Bluetooth: [bluez](https://git.kernel.org/pub/scm/bluetooth/bluez.git) + [bluez-utils](https://git.kernel.org/pub/scm/bluetooth/bluez.git) + [bluetui](https://github.com/pythops/bluetui) (TUI)
* Print: [CUPS](https://github.com/OpenPrinting/cups)

### GUI Apps

* Browser: [zen-browser](https://github.com/zen-browser/desktop)
* File Manager: [nautilus](https://gitlab.gnome.org/GNOME/nautilus)
* Mail: [evolution](https://gitlab.gnome.org/GNOME/evolution)
* Note: [Joplin](https://github.com/laurent22/joplin)
* Office: [OnlyOffice](https://github.com/ONLYOFFICE)
* Terminal: [kitty](https://github.com/kovidgoyal/kitty)
* Viewer (Image): [ImageViewer](https://gitlab.gnome.org/GNOME/loupe) + [imv](https://sr.ht/~exec64/imv/)
* Viewer (PDF): [Zathura](https://github.com/pwmt/zathura)

### TUI Apps

* Editor: [neovim](https://github.com/neovim/neovim)
* File Manager: [yazi](https://github.com/sxyazi/yazi)
* Git: [lazygit](https://github.com/jesseduffield/lazygit)
* Git commit: [koji](https://github.com/cococonscious/koji)
* Git log: [tig](https://github.com/jonas/tig)
* Jj: [lazyjj](https://github.com/lazyjj-dev/lazyjj)
* Journal: [lazyjournal](https://github.com/Lifailon/lazyjournal)
* Note: [toney](https://github.com/SourcewareLab/Toney)
* Sql: [lazysql](https://github.com/jorgerojas26/lazysql)
* System monitoring: [htop](https://github.com/htop-dev/htop)

### Shell & CLI

* Shell: [fish](https://github.com/fish-shell/fish-shell)
* Prompt: [tide](https://github.com/IlanCosman/tide)

#### Modern CLI Utilities

* [atuin](https://github.com/atuinsh/atuin): SQLite-powered shell history
* [fzf](https://github.com/junegunn/fzf) & [television](https://github.com/alexpasmantier/television): Fuzzy finders
* [zoxide](https://github.com/ajeetdsouza/zoxide): Smarter `cd` command
* [eza](https://github.com/eza-community/eza): Modern `ls` replacement
* [bat](https://github.com/sharkdp/bat): Syntax-highlighted `cat` clone
* [fd](https://github.com/sharkdp/fd): Simplified, faster `find` alternative
* [rg (ripgrep)](https://github.com/BurntSushi/ripgrep): Blazing fast `grep` alternative
* [dysk](https://github.com/Canop/dysk): Better disk information display
* [chezmoi](https://github.com/twpayne/chezmoi): Robust dotfiles manager
* [tealdeer](https://github.com/dbrgn/tealdeer): High-performance `tldr` client in Rust
* [tmux](https://github.com/tmux/tmux): Terminal multiplexer
* [trash-cli](https://github.com/andreafrancia/trash-cli): Safe command-line trashcan management
* [gh](https://github.com/cli/cli) & [glab](https://gitlab.com/gitlab-org/cli) & [fgj](https://codeberg.org/romaintb/fgj): GitHub/GitLab/Codeberg CLI hubs
