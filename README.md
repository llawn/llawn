## Projects

* **[buffer-change.nvim](https://github.com/llawn/buffer-change.nvim)**: Diff the current buffer against any Git ref
  with inline annotations (`mini.diff`).
* **[pack-utils.nvim](https://github.com/llawn/pack-utils.nvim)**: Floating UI to manage plugins installed with `vim.pack`.
* **[telescope-gitignore.nvim](https://github.com/llawn/telescope-gitignore.nvim)**: Pick and insert `.gitignore` templates.
